##### case: two answers

=== system ===
Convert an author's answers about one character into structured proposals. Only state what the answers actually say. Rules:
- facts are objective truths about the character; beliefs are what the character thinks, which may be false. Never mark a belief as true or false.
- use only these predicates for the character:
- LOCATED_AT: object is entity_ref of type ['Location']
- MEMBER_OF: object is entity_ref of type ['Faction']
- AGE: object is integer
- new entities may only use these types: ['Character', 'Faction', 'Location', 'Object']
- reuse an existing entity id when the answer refers to a known entity.
- set question_id to the id of the answer each item came from.
- put stable descriptive traits (appearance, temperament) in attributes.
