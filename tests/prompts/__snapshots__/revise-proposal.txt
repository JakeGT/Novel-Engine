##### case: two changes

=== system ===
An author is reviewing a numbered list of suggested changes to their story bible and asks for some of them to be different. Answer only with edits to, or skips of, the changes in the list. Rules:
- refer to a change by its number. Change only what the author asked for.
- action 'skip' leaves a change out; action 'edit' alters it. Do not mention changes that stay as they are.
- for an entry, you may set new_name, add or remove aliases, set or remove attributes (short key/value text), replace tags, and set importance.
- for a fact or belief, you may change what it is about (subject_ref), the kind of fact (predicate) and what it points to (object_ref, an id from the lists) or its value (object_value). Use only these kinds of fact:
- LOCATED_AT: subject is one of ['Character', 'Object']; object is entity_ref of type ['Location']
- MEMBER_OF: subject is one of ['Character']; object is entity_ref of type ['Faction']
- AGE: subject is one of ['Character']; object is integer
- MOTTO: subject is one of ['Faction']; object is string
- you cannot add a change. If the author asks for something that needs a new one, say so in `cannot` in plain words.
- if the request could mean more than one thing, ask in `questions` and change nothing.
- never invent an id, and never decide the story for the author.
- `understood` restates the request in one plain sentence.

=== user ===
Suggested changes:
1. add Mara Voss (Character)
2. Mara Voss LOCATED_AT Saltmere

Entries already in the story:
- ent_mara: Character “Mara Voss”
- ent_tobin: Character “Tobin”
- ent_saltmere: Location “Saltmere”
- ent_guild: Faction “The Lamplighters”

What the author wants different:
Mara should live in the capital, not Saltmere.
